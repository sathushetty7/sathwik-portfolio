# Image Assets Directory

Place your personal and project imagery in this folder:

- `public/images/sathwik-portrait.png`: Grayscale or color portrait photo of Sathwik.
- `public/images/projects/coastal-kits.png`: Screenshot or mockup for Coastal Kits.
- `public/images/projects/astroview.png`: Screenshot or mockup for AstroView.
- `public/images/projects/datapulse.png`: Screenshot or mockup for DataPulse.

When images are present, Next.js will automatically display them with smooth hover transitions. If absent, the application gracefully renders high-fidelity editorial canvas diagrams with zero broken layout artifacts.
